# ALU-Operation
This project implements an 8-bit Arithmetic Logic Unit (ALU) in Verilog. 
The ALU supports 16 operations including arithmetic (addition, subtraction, multiplication, division), 
logical (AND, OR, XOR, NOR, NAND, XNOR), shift/rotate operations, and comparisons (greater-than, equal). 
A comprehensive testbench is provided to verify functionality using Icarus Verilog or EDAPlayground. 
Waveform outputs are generated via VCD files for debugging and visualization in GTKWave.
